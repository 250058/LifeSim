# LifeSim 개정 계획

2026-10-29 사용자 승인 사항을 반영한 현재 제품 계획이다. 원기획과 충돌하는 부분은 이 문서의 개정 사항을 적용한다. 구현 완료 여부는 별도의 검토 보고서와 검증 결과로 확인한다.

## 사용자가 원하는 방향

> 현실에서 일어날 수 있는 그 어떠한 사소한 사건도 검열하지 말고 전부 구현되었으면 좋겠다.

큰 성공이나 비극뿐 아니라, 아무 일 없어 보이는 하루의 불편·즐거움·관계 변화까지 계속 확장한다. 불편하거나 부정적이라는 이유만으로 현실의 사건을 목록에서 빼지 않는다. 범죄·피해·질병·가난·차별·갈등·실패·회복도 발생 조건, 선택, 결과, 장기 영향으로 다룬다.

목표는 수천억~수조 가지의 의미 있는 상황 조합과 높은 행동 자유도다. 기존 기획은 이 목표에 맞게 수정할 수 있다. 사건 150/300/600/1,000개는 제작 이정표로 두고, 작성한 규칙 수·도달 가능한 상황 조합·인생 경로·실제 관측 다양성을 별도로 검증한다. 사건의 포함 범위, 발생 빈도, 화면에 보여줄 분량도 별도로 설계한다.

## 개정 계획 자유도와 상황 생성

2026-10-29 사용자 추가 지시를 반영한다. 기존 계획은 수정할 수 있으며, 자유를 최대한 보장하고 수천억~수조 가지 상황을 목표로 한다. 이 절을 이후 기획 개정과 검토의 기준으로 삼는다. 아래 구조는 구현 목표이며 현재 코드가 이미 지원한다는 뜻은 아니다.

### 자유의 기준

플레이어가 목표를 정하고 행동의 대상, 방식, 시점, 투입 자원을 선택할 수 있게 한다. 정해진 순서의 진학·취업·결혼·성공 경로를 강제하지 않는다. 거절, 연기, 중단, 재시도, 우회, 타인에게 부탁, 여러 목표 병행도 상태가 허용하는 범위에서 열어 둔다.

행동의 제한은 시간·자원·신체 상태·장소·타인의 의사처럼 세계 안에서 설명할 수 있어야 한다. 게임 속 위법 행위는 시도 가능성과 발각·피해·사회적·법적 결과를 모델링한다. 작가가 원하지 않는 결말이라는 이유만으로 행동을 막거나 성공을 강제하지 않는다. 자유에는 실패와 예상 못 한 결과도 포함된다.

행동 메뉴에는 가능한 행동과 관련 조건을 설명하고, “세계에서 불가능”, “조건을 갖추면 가능”, “현재 엔진이 아직 지원하지 않음”을 구분한다. 미구현을 세계의 규칙처럼 포장하지 않는다. NPC도 자신의 목표와 기억에 따라 거절하거나 먼저 행동할 수 있다.

### 성인기의 술 담배와 약물

사용자 요청에 따라 성인 캐릭터에게 음주·흡연·마약류 사용을 선택할 수 있는 행동과 사건을 추가한다. 성인이 되는 것은 선택지를 여는 조건이며, 사용을 자동으로 시작하게 하지는 않는다. 사용하지 않기, 권유 거절, 줄이기, 중단하기, 도움 요청도 같은 시스템에서 다룬다. 이 절은 승인된 구현 목표이며 현재 코드의 구현 완료를 뜻하지 않는다.

| 분야 | 열어 둘 선택과 상황 | 연결할 상태와 결과 |
| --- | --- | --- |
| 술 | 혼자 또는 모임에서 마시기, 회식 권유 거절, 음주 빈도 줄이기, 금주 | 지출, 취기, 판단·활동 능력, 숙취, 수면, 업무·학업, 관계, 누적 건강 영향 |
| 담배 | 흡연 시작·지속, 흡연 장소 선택, 일반 담배·전자담배, 줄이기, 금연 시도 | 지출, 갈망, 의존, 금단, 체력·건강, 냄새·간접흡연을 둘러싼 관계와 장소 규칙 |
| 마약류 | 권유를 받음, 거절 또는 사용 선택, 반복 사용, 중단, 치료·지원 요청 | 급성 이상 반응, 의존·금단, 금전·직업·관계 변화, 응급상황, 지역·시대별 법적 결과, 회복과 재발 |

게임 속 불법 약물 사용도 선택과 결과로 모델링한다. 성인 여부와 행위의 합법성은 별개이며, 주류·담배의 구매 자격과 장소 규칙, 마약류의 법적 상태는 지역·시대별 제도 데이터로 판정한다. 의료진 지시에 따른 처방 사용과 오남용·불법 사용을 구분한다.

사용 경험, 빈도와 누적 노출, 급성 영향의 남은 시간, 갈망·내성·의존, 금단, 중단·치료 이력, 회복 상태를 구분한다. 물질마다 다른 영향과 개인차를 반영하고, 한 번 사용하면 반드시 중독되거나 모든 사용이 즉시 검거로 끝나는 식의 고정 결말을 피한다. 단기 체감 효과와 장기 비용을 함께 반영하고 위험 수치는 근거와 불확실성을 기록한다. 약물 사건은 추상화한 유형과 상태 변화로 구현한다.

회식의 음주 권유 → 수락 또는 거절 → 귀가·다음 날 컨디션 → 동료 관계와 업무 결과처럼 일상 시스템에 연결한다. 스트레스, 주변 사람, 주거 환경, 직업, 건강, 돈, 과거 회복 경험에 따라 같은 선택의 결과가 달라지게 한다. 다른 물질 사용과 기저 건강 상태가 겹치는 경우도 위험 판정의 입력으로 다룬다.

치료·금연·금주·회복에는 시간, 비용, 접근성, 주변 지원이 영향을 준다. 회복 중 실수나 재발이 생겨도 다시 도움을 구할 경로를 유지한다. 진단·상담·응급 대응은 게임의 의료 체계와 연결한다.

완료 기준:

- 성인 여부를 메뉴 표시, 사건 선택지, 실제 행동 처리에서 일관되게 검사한다. 성인이 된 뒤에도 선택하지 않으면 사용 이력이 생기지 않는다.

- 사용·거절·감량·중단·치료를 각각 실행할 수 있고, 선택한 물질에 맞는 시간·돈·건강·관계 변화가 남는다.

- 지연된 건강 영향과 회복 상태는 저장·재개 후 유지되며, 같은 행동이 두 번 결제되거나 효과가 중복 적용되지 않는다.

- 물질과 맥락별 급성 영향, 의존, 금단, 회복, 법적 반응을 구분하고, 실제 통계와 다른 임의의 보정은 표시한다.

- 기존 직업·가족·건강·사법 사건과 연결되는 경로 및 사용하지 않는 경로를 함께 검증한다.

### 상황을 만드는 구조

상황은 사건 규칙, 참여자 관계, 장소와 시간, 개인·가구·기관 상태, 세계 환경, 관련된 과거, 가능한 행동, 결과 규칙의 결합으로 생성한다. 호환되지 않는 조합은 조건 검사로 제거하고, 의미 있는 상호작용이 없는 차이는 새 상황으로 세지 않는다.

| 구성 요소 | 담아야 할 내용 |
| --- | --- |
| 지속되는 세계 | 인물, 가구, 물건, 장소, 학교·회사·병원 등 기관, 계약, 권리·의무 |
| 행동 | 행위자, 대상, 방식, 시점·기간, 비용, 선행 조건, NPC 반응 |
| 사건 규칙 | 노출 조건, 위험도와 시간 단위, 관련 인물, 충돌·취소 조건, 즉시 효과 |
| 결과와 기억 | 상태 변화, 원인이 된 사건 ID, 기억·신뢰 변화, 지연 효과, 후속 사건 |
| 상황 생성 | 유효한 역할과 맥락을 결합하고, 현재 상태에 맞는 행동과 결과를 구성 |
| 표시 | 중요한 결정은 카드로, 작은 변화는 일기·알림·연말 요약으로 표시 |

예를 들어 “지갑 분실”도 출근길인지 여행 중인지, 카드가 정지됐는지, 마지막 교통비가 남았는지, 가족에게 도움을 청할 수 있는지, 습득자가 누구인지에 따라 선택과 결과가 달라진다. 교통비 부족 → 지각 → 기존 근태와 결합한 직장 반응 → 동료에게 도움 요청 → 신뢰·차용 관계 → 나중의 관계 사건으로 이어지게 한다. 명칭만 다른 분실 카드를 복제하는 방식으로는 이 다양성을 얻을 수 없다.

### 수천억에서 수조 가지를 검증하는 방법

목표는 수천억~수조 규모의 의미 있는 상황 조합을 표현하고 필요할 때 생성할 수 있는 엔진이다. 다음 지표를 섞어서 완료를 주장하지 않는다.

| 지표 | 의미 | 집계 원칙 |
| --- | --- | --- |
| 작성한 콘텐츠 | 사람이 작성·검수한 규칙, 행동, 이야기, 표현 | 문장 변형은 별도로 센다 |
| 가능한 상황 조합 | 조건을 만족하고 선택·결과에 차이를 만드는 상태 조합 | 관계·제도·노출 등 제약을 반영한다 |
| 인생 경로 | 여러 상황과 선택이 시간 순서로 연결된 경로 | 단일 상황의 개수와 구분한다 |
| 실제 관측 다양성 | 자동 플레이에서 도달한 서로 다른 상황과 경로 | 표본 크기·선택 정책·버전을 함께 기록한다 |
| 체감 다양성 | 반복률, 같은 선택의 맥락별 결과 차이, 발견 가능한 새 행동 | 실제 플레이와 대표 사례로 확인한다 |

계산 원리를 보여 주는 가정 예시로, 독립적인 결정 20번에 매번 의미가 다른 선택이 4개씩 있으면 4의 20제곱 = 1,099,511,627,776개의 잠재 경로가 된다. 실제 게임에서 모든 선택이 가능하거나 서로 독립적이라는 뜻은 아니며, 이 수를 구현된 상황 수로 사용할 수 없다.

상황의 식별 기준에는 결과에 영향을 주는 관계·자원 구간·제도·과거 원인·행동 가능성 등을 넣는다. 이름, 시드, 문장, 의미 없는 숫자 차이만으로 새 상황을 세지 않는다. 자원 구간을 나눌 때도 행동 가능 여부나 결과가 바뀌는 경계에 근거한다.

조합 수를 발표할 때는 사용한 축, 상호 제약, 중복 제거 기준, 계산 방법, 엔진 도달성 근거를 함께 남긴다. 정확히 계산한 범위, 검증한 하한, 추정한 범위를 분리한다. 이론적 조합 수가 커도 특정 사건이 계속 반복되면 체감 다양성은 미달이다.

### 대규모 조합을 실행하는 방법

수조 개의 완성된 사건 파일을 저장하지 않고, 규칙과 현재 상태를 바탕으로 필요한 순간에 조합한다. 시간마다 모든 사건을 전부 검사하기보다 나이·장소·소속·태그별 후보를 찾고, 상태 변화와 예약된 결과가 있을 때 관련 규칙을 평가한다.

플레이어와 가까운 인물·기관은 자세히 계산하고 먼 영역은 요약해서 갱신할 수 있다. 다시 등장할 때 과거 사실과 충돌하지 않아야 하며, 이미 결정한 중요한 사건을 화면 밖에 있었다는 이유로 다시 추첨하지 않는다. 기억을 요약하더라도 후속 조건에 필요한 사실과 원인 연결은 보존한다.

AI는 선택적으로 자유 입력을 구조화하거나 표현을 다양화할 수 있다. 판정과 상태 변경은 검증 가능한 엔진을 거친다. 자유 입력의 의미를 해석하지 못했을 때는 가능한 행동으로 연결하거나 미지원이라고 설명하며, 수행하지 않은 행동을 성공했다고 서술하지 않는다.

재현에는 시드, 시작 설정, 엔진·콘텐츠 버전, 행동 기록, 지연 결과를 사용한다. 콘텐츠가 늘어도 기존 저장을 다룰 버전 정책을 정한다. 속도 목표는 측정 기기와 활성 인물·후보 사건 규모를 명시해 검증하며, 조합 규모만으로 성능을 보장하지 않는다.

### 구현 순서와 통과 기준

1. **행동과 시간 모델부터 정리한다.** 돈 빌리기, 부탁하기, 거절하기, 이동하기, 일하기, 쉬기 같은 재사용 행동을 대상으로 장소·시간·자원·관계 조건을 처리한다. 서로 겹치는 약속과 지출을 같은 규칙으로 검증한다.

2. **작은 사건의 전체 흐름을 완성한다.** 집·이동·직장·관계·건강 중 여러 분야를 연결하는 일상 사슬을 만든다. 시작부터 장기 결과, 취소, 저장·재개까지 확인한다.

3. **같은 규칙을 다양한 맥락에서 조합한다.** 인물·가구·제도·지역·과거 조건을 바꾸어 가능한 행동과 결과가 실제로 달라지는지 확인한다. 주요 축의 두세 가지 교차 조건과 드문 경계 조건부터 점검한다.

4. **NPC와 기관의 자율 행동을 연결한다.** 플레이어의 선택을 기다리는 동안에도 약속·계약·관계·세계가 변하게 한다. 플레이어가 개입해도 기존 사실과 인과가 유지되는지 검증한다.

5. **콘텐츠와 도달 범위를 계속 늘린다.** 기존 일상 사건 22개 분야와 원기획의 대형 아크를 확장한다. 매 단계마다 도달성, 반복률, 자유 행동 지원 범위, 인과 오류, 저장 재현, 실행 비용을 보고한다.

### 정기 검토에 추가할 기준

매 회차 자유를 제한하는 불필요한 고정 순서·숨은 차단·선택 강제를 찾는다. 새 상황이 기존 규칙과 결합하는지, 선택의 차이가 상태와 후속 결과에 남는지, 독립적인 NPC가 있는지, 작은 사건이 표시 상한 때문에 사라지는지 확인한다.

목표를 방해하는 기존 기획은 수정할 수 있다. 변경마다 기존 결정, 새 결정, 이유, 이미 구현한 코드·데이터·저장 형식에 미치는 영향, 검증 기준을 남긴다. 사용자가 허용한 범위의 기획 수정을 매번 다시 승인받을 필요는 없다. 코드 구현과 병합·배포 여부는 기존 검토 업무 범위와 별개로 유지한다.

## 사건 한 개를 구현했다고 인정하는 기준

1. 고유 ID, 분야, 규모, 발생 조건, 시간 단위, 확률/노출량, 출처 또는 추정 근거가 있다.

2. 등장인물·장소·대상은 실제 상태와 일치한다. 이미 사망한 NPC, 끝난 직장, 없는 물건이 잘못 재등장하지 않는다.

3. 선택 또는 자동 처리의 결과가 돈·시간·건강·관계·기억 중 관련 상태에 반영된다. 소소한 감정과 기억만 남는 사건도 허용한다.

4. 반복·쿨다운·동시 발생·상호 배타·취소·사망 시 정리 규칙이 있다.

5. 즉시 결과뿐 아니라 필요한 지연 결과가 예약되고, 저장·불러오기 후에도 한 번만 실행된다.

6. 후속 사건과 종료 조건이 연결된다. 이전 사건이 수십 년 뒤 등장하면 같은 인물과 기억을 참조한다.

7. 조건을 구성한 도달성 사례와 핵심 선택 결과를 검증한다. 미발생이 정상인 경우도 검증한다.

8. 표현 설정과 로그 요약 수준을 바꿔도 시뮬레이션 상태가 임의로 삭제되지 않는다.

예시 인과 사슬: 보일러 고장 → 수리비·추위·외출 일정 변경 → 일을 빠지거나 이웃에게 도움 요청 → 소득·건강·이웃 신뢰 변화 → 나중의 도움·갈등 사건. 이런 연결을 먼저 몇 개 완성한 다음 분야별로 확장한다.

### 기본 경험과 검증

새 인생의 기본 모드는 현실(reality)로 한다. 드라마·막장 모드도 사용자가 선택할 수 있으며, 이미 저장된 인생과 사용자가 선택한 모드를 임의로 바꾸지 않는다. 현실 모드 검증과 연출 모드의 빈도 설정을 분리한다.

전체 평균 수명 하나로 현실성 보정을 완료 처리하지 않는다. 성별·연령별 생존, 혼인, 출산, 경제, 사건 도달성·반복률에 각각 기간·분모·표본 수·선택 정책·불확실성을 기록한다. 모든 성별 인생의 평균 자녀 수는 기간 합계출산율과 직접 비교하지 않는다. 생성된 사건 ID, 실제 도달한 사건, 의미 있는 상황 조합을 따로 센다.

콘텐츠가 추가되거나 화면 카드 수가 바뀌어도 같은 노출의 발생 확률과 후속 상태는 유지되어야 한다. 조건에 맞지 않는 후보가 늘어났다는 이유만으로 유효 사건이 사라지는 추첨을 피한다. 실제 발생 기록, 자동 상태 변화, 사용자의 결정을 기다리는 사건, 화면 요약을 분리한다. 화면에서 생략한 결정을 사용자가 선택한 것으로 처리하지 않는다.

### 세대 전환과 지속되는 인물

자녀로 이어하기는 같은 인물의 시점을 바꾸는 동작이다. 알려진 생년·건강·관계·재산·사건 이력을 보존하고, 아직 생성되지 않은 과거만 기존 사실과 모순되지 않는 조건 안에서 채운다. 부모와 배우자 등은 연결된 인물 ID로 관리하고, 재혼 상대를 모든 자녀의 친부모로 단정하지 않는다.

나이와 생년, 관계 시작 시점, 자격, 생존 상태를 공통 검증한다. 미래에 시작할 관계가 현재 이미 존재하거나, 나이 구간이 역전된 채 추첨되지 않게 한다. 세대가 바뀌어도 지연 사건과 기존 인과의 처리·취소 근거를 보존한다.

### 성인 선택과 노출 이력

술·담배·약물의 사용, 거절, 감량, 중단, 치료는 주인공의 행동 기록과 상태로 남긴다. 성인이 됐다는 이유만으로 첫 사용·숙취·중독 이력을 생성하지 않는다. 사용 후속 사건은 실제 노출과 경과 시간에서 예약하고, 저장·재개 후 한 번만 처리한다. 거절이나 중단을 선택하면 서술만으로 다음 사용을 확정하지 않는다.

본인의 성인 여부, 상대의 성인 여부가 필요한 활동, 지역·시대별 합법성·자격은 각각 판정한다. 독신도 가능한 행동에 커플 조건을 일괄 요구하지 않는다. 메뉴뿐 아니라 사건 선택지와 실제 행동 처리에서 동일 규칙을 적용한다. 주변인의 사용·권유 같은 현실 사건과 주인공이 실행할 수 있는 행동은 구분한다.

구현 완료 전에는 새 상태를 추가했다는 이유만으로 기존 저장의 과거 선택을 임의로 만들어 넣지 않는다. 불명 상태는 불명으로 남기고 버전 이전 정책에 따라 처리한다.

- 사용자가 선택한 행동·계획의 효과를 설명하는 태그는 관련 행동 처리, 무작위 사건과 예약 결과에 일관되게 연결한다. 피임·임신 준비처럼 확률에 영향을 주는 선택은 방법·기간·노출·실패 가능성과 추정 근거를 구분한다. 하나의 선택이 결과를 보장하지 않으며, 설명만 바뀌고 같은 결과 분포가 유지되는 미구현도 완료로 표시하지 않는다.
- 피임 방법은 사용 주체의 인물 ID와 적용 기간·중단 이력에 연결한다. 주인공 본인의 방법과 상대의 방법을 구분하고, 이별·이혼·사별·재혼으로 이전 상대의 방법이 새 상대에게 넘어가지 않게 한다. 같은 해의 관계 변경도 ID로 구별한다. 활동·임신 사건·예약 결과는 같은 인물별 방법 조회를 사용한다. 구저장에 사용 주체가 없으면 불명으로 보존하고 새 상대에게 임의 배정하지 않는다. 같은 상대와의 혼인, 다른 상대와의 재혼, 관계 변경 중 저장·재개를 교차 검증한다.
- 선택을 기다리는 카드는 사건 ID와 함께 안정적인 선택지 ID, 선택지 정의의 콘텐츠 버전을 보존한다. 배열 번호만 유지한 채 다른 의미의 선택지로 바꾸지 않는다. 저장 재개·관계/나이/자원 변경·콘텐츠 갱신 시 현재 실행 조건을 다시 확인하고, 아직 고르지 않은 제안과 이미 실행한 선택을 구분한다. 유효하지 않은 선택은 이유와 새 선택 집합을 제시하며 임의 실행하지 않는다. 이전 선택지의 의미를 확인할 수 없는 구저장은 명시된 이전/중단 정책으로 처리한다. 선택 대기 중 저장, 같은 버전 재개, 다음 콘텐츠 버전 재개를 교차 검증한다.
- 저장·재개와 세대 전환에서도 대상 ID와 취소 근거를 보존한다. 과거 저장에 대상이나 방법이 없으면 임의의 가족·행동으로 채우지 말고 명시된 이전 정책으로 처리한다. 두 자녀 중 한 명만 대상인 사건, 대상의 사망·전학·관계 변화, 화면 문구 변경, 중복 재개를 경계 검증에 포함한다.
