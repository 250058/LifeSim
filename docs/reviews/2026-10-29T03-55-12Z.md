[eventEngine.ts:182](https://github.com/250058/LifeSim/blob/9a7905569e2c6904f2c2a8581590c857cc6575e0/src/engine/eventEngine.ts#L182)는 전체 풀에서 최대 80번 거절 추첨하고, 배수는 `min(1, x)`로 받는다. 유효 후보의 가중치 비중이 q라면 실패 확률은 `(1-q)^80`이므로 무관한 후보를 추가해도 실제 발생률이 달라질 수 있다. 표본 상태 `REVIEW-POOL`, 여성 5세에서는 유효 가중치가 약 4.28%라 80회 모두 놓칠 확률이 약 3.02%다. 1보다 큰 보정도 잘려 상대 가중치가 보존되지 않는다. 조건별 후보 인덱스 또는 정확한 가중치 추첨으로 최적화하고, 콘텐츠 증설 전후에 동일 노출의 발생률이 유지되는지 검증한다.

## 재현 부록

대상 SHA의 검토용 작업 사본에서 다음 형태의 상태를 만들었다. 실제 플레이의 발견 빈도를 추정하기 위한 표본이 아니라, 정상적으로 표현 가능한 가족·나이 조건에서 함수의 경계를 검증한 것이다.

```ts
import { newGame } from './src/engine/game';
import { haveChild } from './src/engine/relations';
import { continueAsChild } from './src/engine/heir';
import { rngFor } from './src/engine/rng';

function fixture(seed: string, kidAge: number, pi = 1) {
  const p = newGame({ seed, mode: 'reality', birthYear: 2026 });
  p.ch.age = kidAge + 30;
  p.year = p.ch.birthYear + p.ch.age;
  p.world.year = p.year;
  p.world.economy.priceIndex = pi;
  p.ch.npcs = [];
  const child = haveChild(p, rngFor(seed, 'child'));
  child.birthYear = p.year - kidAge;
  p.ch.alive = false;
  p.phase = 'dead';
  p.ch.death = { age: p.ch.age, year: p.year, cause: 'review fixture' };
  return { p, child };
}
const { p, child } = fixture('REVIEW-HEIR-6', 10);
const next = continueAsChild(p, child.id)!;
console.log(next.ch.age, next.ch.npcs.filter(n => n.role === 'spouse'));
// 10세 주인공, 9세 배우자, since: 21
```

연금 사례는 `fixture('REVIEW-PENSION', 65)`를 만든 뒤 같은 부모 상태를 복사해 `priceIndex`만 3으로 바꾸고 두 결과의 `career.avgSalary`, `career.pension * priceIndex`를 비교하면 된다. R-008·R-009는 19세/13세 상태에 각각 `phys_first_hangover`/`first_cigarette`을 `presentCard`로 전달하고 조건·선택 효과를 확인한다. R-010의 난수 인덱스는 1이다.
