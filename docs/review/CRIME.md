# 범죄 피해·목격·지원과 기관 처리 (Codex U-002)

이 문서는 U-002 묶음의 범위·기존 사건 대조·상태 모델·근거·검증을 적는다. **기획 반영, 데이터 작성, 엔진 연결, 검증 완료를 구분해 적었다.**
구현 완료나 전수 검토 완료 선언이 아니다. 아래 "미구현과 후속"에 남은 일을 적었다.

- 엔진: `src/engine/crime.ts` (사건 기록·대응·기관 단계·회복·조건식 값·사건표 검사)
- 표 펼치기: `src/engine/catalog/crime.ts` (범주 규칙, 장면·단계 → 사건 정의)
- 데이터: `data/catalog/crime.json` (출처, 기관, 맥락, 장면, 단계 카드, 결과 문장)
- 기존 사건: `data/events/disaster.json`의 `random_attack`을 **복제하지 않고** 사건 기록에 연결했다
- 검증: `tests/crime.test.ts`, `npm run validate`의 범죄 규칙 (`crimeDataProblems`)

## 1. 수를 세는 기준

작성 규칙, 의미 있게 다른 상황, 생성된 사건 ID를 따로 센다. 생성된 ID 수를 상황 수로 쓰지 않는다.

| 구분 | 수 | 무엇을 센 것인가 |
| --- | --- | --- |
| 작성 규칙: 범주 규칙 | 20 | 법정형·공소시효·보호조치·반의사불벌·친고죄·추정 처리 비율이 다른 범주 (`CATEGORY`) |
| 작성 규칙: 맥락 | 25 | 장소·관계 (직장·학교·대학·온라인 등. 조직 처리 주체가 다르다) |
| 작성 규칙: 장면 행 | 90 | 범주 × 맥락 × 역할 한 줄. 이 중 1줄은 기존 `random_attack`(사건 정의는 disaster.json), 7줄은 아동·청소년 보호 장면 |
| 작성 규칙: 단계 카드 | 14 | 수사·검찰·재판·선고·조직 조사·진정·민사·보호조치·재발·다시 돌아보기·참고인·지원·소식·회복 |
| 작성 규칙: 대응 처리기 | 43 | `CRIME_ACTS` (피해자·목격자·지원자·보호자·기관 단계의 선택) |
| 작성 규칙: 기관 | 23 | 사건 기록에 id로 남는 기관 (`institutions`) |
| 작성 규칙: 결과 문장 키 | 276 키 / 283 문장 | 엔진이 상태에 따라 고르는 문장 |
| 범주 × 맥락 × 역할 조합 | 79 | 장면 행 중 서로 다른 조합. 의미 상황의 상한이 아니라 작성 범위 |
| 장면 × 첫 대응 분기 | 359 | 장면 선택지 수 (기존 `random_attack` 3개 포함). 대응마다 상태 변화가 다르지만 **도달·의미 검증값이 아니다** |
| **생성된 사건 ID** | 103 | `catalog/crime.json`이 만드는 사건 정의 (장면 89 + 단계 14). 상황 수가 아니다 |

의미 있게 다른 상황은 "같은 사건 번호에 쌓인 상태"(범주·역할·피해자 나이·신고 경로·기관·처분·보호조치·회복)로 판단한다.
현실 모드 1,000명 표본에서 관측한 서로 다른 경로는 6절에 따로 적었다. 이름·문장·시드만 다른 경우는 세지 않는다.

## 2. 기존 사건 대조 (기존 / 이번에 더함 / 미구현)

### 2.1 범주별 표

"기존"은 이 묶음 전부터 있던 사건, "더함"은 이 묶음의 장면 행(피해 V, 목격 W, 지원 S, 아동·청소년 보호 M)이다.

| 범주 | 기존 사건 | 더함 (장면 행) | 미구현·한계 |
| --- | --- | --- | --- |
| 이상동기 폭행 | `random_attack` (disaster.json, 목격·개입·신고) | `random_attack`을 사건 기록에 연결(복제 안 함), 피해자 장면 V1 | 사건 직후 집단 트라우마 지원 체계, 모방 범죄 경보 |

| 온라인 그루밍 | 없음 | **M1** (아청법 15조의2, 피해자는 아동·청소년뿐) | 위장 수사, 플랫폼 신고 의무 |
| 사기 | `voice_phishing` 아크(피해·가담), `jeonse_fraud`, `scam_compound` 아크 | V6(중고거래·쇼핑몰·리딩방·지인 대여·구인·청소년 게임) S1 | 기존 보이스피싱·전세사기 아크를 같은 사건 기록으로 옮기기 |

| 온라인 괴롭힘 | 없음 | V3(성인·직장 단톡방·청소년 게임 커뮤니티) W1 | 학교폭력 아크(`school_violence`)의 사이버폭력과 합치기 |

기존 아크 중 `school_violence`(학교폭력), `military_abuse`(군 가혹행위), `voice_phishing`, `scam_compound`는 자기 사건 흐름을 그대로 둔다.
이번 사건 기록(`ch.crime`)과는 아직 연결하지 않았다. 같은 피해를 두 번 세지 않도록 이번 장면은 그 아크의 상황(학교 안 집단 괴롭힘, 군, 보이스피싱 전화, 해외 범죄단지)을 다시 만들지 않았다.

### 2.2 `random_attack`

기존 카드 문장·선택지·확률(`4e-05`, 수도권 ×1.5, 평생 1회)은 그대로다. 사건이 뜨면 `crime open random_attack`으로 사건 번호가 생기고,
선택지는 각각 `avoid`·`intervene`(판정 실패 시 `hurt`)·`report`로 이어진다. 신고하면 1년 뒤 참고인 카드와 소식이 같은 사건 번호로 온다.
바뀐 점: 판정 실패 결과에서 영구 `ptsd` 태그 대신 회복 곡선을 따르는 `crime_aftermath`(사건 후유증, 회복하면 사라짐)를 쓴다.
번호 없이 저장된 옛 카드는 예전처럼 처리된다 (테스트).

## 3. 사건 기록과 단계

### 3.1 지속되는 ID

- 사건 번호 `k<카드 일련번호>`: 발생부터 모든 단계 카드가 `ctx.caseId`로 같은 사건을 읽는다.
- 참여자 id: 기존 NPC면 `p<NPC id>`(연인·배우자·부모·전 배우자·친구·형제·자녀·보호자), 아니면 `p<일련번호>o/v`. 같은 직장의 같은 가해자는 같은 id로 다시 나온다.
- 미성년 피해의 보호자: `guardian`에 'self'(주인공이 보호자) 또는 보호자 참여자 id(부모 NPC와 묶임). 가해자인 부모는 보호자가 되지 않는다.
- 기관 id: 단계 기록(`log[].inst`)에 남는다. `institutionsOf(case)`가 처음 닿은 순서로 돌려준다. 움직인 사람은 `log[].by`.
- 같은 가해자의 사건이 아직 열려 있으면 새 장면은 새 사건이 아니라 그 사건의 재발이다.

### 3.2 단계는 따로 둔다

| 단계 | 값 | 비고 |
| --- | --- | --- |
| 발생 | `occurred`, 나이·연도, 피해 정도, 금전 피해, 다침 | 몇 해 전 일을 털어놓는 지원 장면은 그때로 기록 |
| 신고 | none / immediate / delayed, 신고한 사람(본인·피해자·주변·보호자·학교) | 신고하지 않은 사건도 기록과 회복이 남는다 |
| 수사 | investigating / no_suspect / referred / not_sent, 지연 여부, 특정 여부 | 20% 지연, 모르는 가해자는 범주별 특정 확률 |
| 검찰 | indicted / summary / deferred / dropped / no_right / juvenile | 이의신청·항고 경로 |
| 재판·판결 | ongoing / done, prison / suspended / fine / acquitted / dismissed | 무죄면 항소 의견 |
| 조직 처리 | raised / action / no_action / retaliation / ended, 징계 여부 | 직장 고충·학교폭력 전담기구·대학 인권센터 |
| 행정 | 고용노동부 진정·국가인권위원회·노동위원회 → ordered / dismissed | |
| 민사 | filed / won / settled / lost (승소해도 집행 불능 가능) | 민법 766조 기한, 미성년 성적 침해는 성년부터 |
| 보호조치 | granted / denied / violated / ended, 종류(스토킹 잠정조치·가정폭력 임시조치·신변보호) | 위반 신고 경로 |
| 상담·치료 | none / active / done, 연결 기관 | |
| 회복 | 회복도 = 출발점 + 속도 × 시간, 85 이상이면 회복 | 지원·상담·가족 지지가 빠르게, 이어지는 위협이 느리게. 개인차 0.75~1.25 |

### 3.3 원칙과 그 구현

- **신고·대면을 강제하지 않는다.** 장면마다 조건 없이 고를 수 있는 신고·대면 외의 길이 둘 이상 있다 (검사 규칙). 다시 돌아보는 카드에는 늘 "아직은 아니다"·"내려놓는다"가 있다.
- **늦은 신고.** 신고하지 않은 사건은 1~2년 뒤 다시 돌아보는 카드가 오고(스스로 미루면 최대 6번), 공소시효·고소기간 안이면 신고된다.
  어릴 때 일은 어른이 된 뒤 한 번 더 돌아본다. 시효가 지나면 신고 대신 그 사실을 알려 준다.
- **기관은 느리거나 틀리거나 도울 수 있다.** 수사 지연, 증거 부족 불송치·불기소·무죄, 조직의 조치 없음·2차 피해, 보호조치 기각·위반, 보호자가 대수롭지 않게 넘김, 민사 승소 뒤 집행 불능이 모두 있다.
- **피해자는 도덕성·평판을 잃지 않는다.** 엔진은 피해로 도덕성·평판을 깎지 않고, 모든 피해 장면의 모든 선택지를 테스트로 확인한다.
- **회복은 사람마다 다르고 평생 고정되지 않는다.** 어떤 피해 장면도 30년 안에 회복 기준에 닿는다 (지원이 없어도 해마다 3 이상).
- **가해자 사망·관계 종료 재검사.** 단계마다 가해자 NPC가 살아 있는지 다시 본다. 숨지면 형사 절차는 공소권 없음, 보호조치는 끝난다(민사는 남을 수 있다).
  이혼·이별·퇴사·연락 끊김, 부모에게 맞던 아이가 집을 떠난 경우는 관계 종료로 보고 재발 위험을 낮춘다. 지원하던 피해자가 숨지거나 연락이 끊기면 다른 사람으로 바꾸지 않고 이유를 남기고 닫는다.

### 3.4 성희롱: 형사·민사·행정·징계를 따로 판정

| 판정 | 규칙 |
| --- | --- |
| 형사 | 말로 한 직장·공공장소·학교 성희롱 자체는 형사 처벌 대상이 아니다. 온라인의 성적 메시지는 통신매체이용음란(성폭력처벌법 13조)으로 형사 절차가 있다. 신체 접촉은 성폭력·성추행 범주로 따로 다룬다 |
| 조직(징계) | 직장 고충 처리(남녀고용평등법 14조), 대학 인권센터, 학교폭력 전담기구 → 교육지원청 심의위원회. 조치·분리만·조치 없음·2차 피해 |
| 행정 | 고용노동부 진정(사업주 조치 의무 위반, 5년), 노동위원회 시정(신고 뒤 불리한 처우, 직장만), 국가인권위원회(업무·고용 관계, 1년). 학생 사이·모르는 사람 사이에는 행정 진정이 없다 |
| 민사 | 가해자를 알고 기한 안이면 손해배상 (형사 유죄가 있으면 이기기 쉽다) |

## 4. 아동·청소년 보호 범위 (Codex 09:52 개정 반영)

3회차 응답에서 미성년 피해를 "비성적 범죄"로 좁혔던 것을 바로잡았다. 아동·청소년의 피해(성범죄 피해 포함)는 **보호·털어놓기·신고·지원·회복** 사건으로 다룬다.

| 장면 | 주인공 | 범주 | 고를 수 있는 길 |
| --- | --- | --- | --- |
| `crime_minor_school_sh` 쉬는 시간 | 12~18세 피해자 | 성희롱(학교 또래) | 선생님에게, 보호자에게, 1388 익명 상담, 아직 말하지 않기 |
| `crime_minor_known_adult` 말하기 어려운 일 | 10~18세 피해자 | 성폭력(아는 어른) | 보호자에게, 선생님에게, 1388, 아직 말하지 않기 |
| `crime_minor_grooming` 친절했던 사람 | 11~18세 피해자 | 온라인 그루밍 | 보호자에게, 117 신고, 디지털성범죄피해자지원센터, 아직 말하지 않기 |
| `crime_minor_deepfake_school` 합성물 | 13~18세 피해자 | 합성물(학교) | 선생님에게, 삭제 지원, 보호자에게, 아직 말하지 않기 |
| `crime_child_abuse` 긴소매 | 7~17세 피해자 | 가정폭력(아동학대, 부모 NPC) | 믿을 만한 어른에게, 선생님에게, 1388, 아직 말하지 않기 |
| `crime_minor_support_friend` 친구의 비밀 | 13~18세, 미성년 친구(NPC)를 돕는다 | 성폭력 | 들어 주기, 어른·1388에 같이 말하자고 하기, 상담 선생님에게 같이 가기, 곁에 있기 |

- **표현:** 행위를 묘사하지 않는다("해서는 안 되는 일"). 성적 행동 선택지가 없다. 미성년 장면에는 돈을 보내거나 요구에 응하는 길, 대면·촬영·퇴사·이사 같은 성인 대응이 없다(`MINOR_SAFE_ACTS`). 플레이어는 어느 나이에도 성범죄를 저지르지 않는다(처벌받는 죄 목록에 성범죄 없음).
- **조건 분리:** 보호 장면에는 성인 전용 표시(`adult`)를 붙이지 않는다. 나이는 장면의 `age`·`childAge`가, 사건 존재·보호자·표현·플레이어 행동은 각각 따로 판정한다. 성인 대상 성범죄 장면은 여전히 성인만이고, 성인 장면의 지원 대상(친구·자녀)도 성인만이다.
- **보호자:** 아이가 부모에게 말하면 그 부모가 보호자로 묶인다. 보호자는 아이와 해바라기센터·디지털성범죄피해자지원센터·아동보호전문기관을 찾아 신고까지 하거나(60%), 상담부터 하거나(25%), 대수롭지 않게 넘긴다(15%, 추정). 넘긴 경우에도 아이는 나중에 다른 어른에게 말할 수 있다. 보호자가 없으면 아동보호전문기관이 함께한다.
- **신고 의무자:** 아이가 선생님에게 말하면 학교가 신고한다(아동학대처벌법 10조 2항, 아청법 34조 2항). 가정폭력을 본 아이도 아동학대(정서적 학대)로 신고된다. 이 길은 플레이어가 선생님에게 말하기를 골랐을 때만 생기고, 익명 상담·미루기는 늘 따로 있다.
- **절차:** 경찰이 미성년 피해자의 신고를 받으면 보호자에게 알린다. 재판에서는 녹화 진술·화상 증언·진술조력인을 고를 수 있고 합의 제안 카드는 띄우지 않는다. 미성년 가해자는 소년부 송치. 미성년자의 민사 소송은 보호자가 법정대리인으로 내고 비용도 보호자가 낸다. 함께 사는 부모를 상대로 한 민사는 성년이 된 뒤에만 열린다. 아이의 치료비를 용돈에서 빼지 않는다.
- **시효:** 미성년 피해의 공소시효는 성년(만 19세)이 된 날부터 흐른다(성폭력처벌법 21조 1항, 아청법 20조 1항, 아동학대처벌법 34조 1항). 13세 미만 대상 성폭력은 시효가 없다(성폭력처벌법 21조 3항). 성적 침해의 민사 시효도 성년부터(민법 766조 3항).
- **검사:** `crimeDataProblems`가 보호 장면의 나이·대응·표현(성적 행위·신체 묘사 낱말 목록)과 보호 경로 결과 문장을 검사하고, 테스트가 실제로 뜬 카드 문장 전체(장면·선택지·결과·이어지는 단계 카드)를 다시 검사한다. 낱말 목록은 보조 수단이며 문장은 사람이 읽고 썼다.

## 5. 연간 기본 확률과 근거

`base`는 그 조건에 있는 사람 1인당 **현실 모드 연간 확률**이다. 현실 모드는 배수 1(디렉터·모드 보정 없음), 드라마·막장은 기존 모드 규칙(`modeMultiplier`)을 그대로 쓴다.

## 7. 저장·재현

- 기록은 `ch.crime`(선택 필드) 한 곳에 있다. 옛 저장에는 없고, 읽을 때 빈 기록으로 본다(`readLedger`). 이 묶음에서 더한 사건 필드(`minor`·`clockFrom`·`civilFrom`·`noLimit`·`guardian`·`adultRevisit`, 기록의 `inst`·`by`)도 모두 선택이며 읽는 곳에서 기본값을 쓴다. `save.ts`는 바꾸지 않았다.
- 난수는 `rngFor(seed, 'crime', …)` 줄기만 쓴다: 장면을 열 때 `('crime','open',장면,나이,일련번호)`, 대응·단계마다 `('crime',사건,op,대응·단계,기록 길이)`. 같은 시드·선택이면 같은 결과이고, 사건 도중 저장·불러오기를 해도 이어지는 단계가 같다 (테스트).
- 사건이 사라진 예약 카드(옛 저장·후계자)는 조건(`crime.case.exists`)이 맞지 않아 조용히 넘어간다.

## 8. 미구현과 후속

- 연애 카탈로그의 교제폭력·스토킹·숙박업소 불법촬영·촬영물 협박 사건(`rom_*`)은 아직 같은 사건 기록을 쓰지 않는다. 같은 사람의 일이 두 경로로 생기면 따로 기록된다(연애 카탈로그 담당 영역).
- 학교폭력·군 가혹행위·보이스피싱·전세사기·범죄단지 아크를 사건 기록으로 옮기는 일.
- 후계자로 이어 하면 부모의 사건 기록은 넘어가지 않는다. 자녀가 피해자였던 보호자 사건을 자녀(새 주인공)의 기억으로 잇는 일은 `heir.ts` 담당과 함께 정해야 한다.
- 화면: 사건 기록·기관 이력을 보여 주는 UI는 없다 (카드·일기·태그로만 보인다).
- 범죄피해자 구조금, 피해자 국선변호사·진술조력인의 세부 절차, 2차 피해(수사 기관), 장애인 대상 범죄, 친족 성폭력, 노인 본인의 학대 피해, 성매매 피해.
- 기관 처리 비율과 보호자 반응 비율의 원표 대조, 지역·시대별 제도 변화(예: 스토킹처벌법 2021 시행 이전).
- `crime_aftermath` 태그는 표시만 하고 건강·행복의 연간 변화에는 쓰지 않는다 (회복 곡선은 사건 기록에 있다).
