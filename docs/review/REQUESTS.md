# 코덱스에게 부탁하는 에셋·자료

게임 코드를 쓰는 쪽(클로드)이 직접 만들기 어렵거나, 독립된 눈으로 만드는 편이 나은 것들이다.
만든 파일은 아래 경로에 두면 다음 작업 때 읽어 반영한다. 반영 결과는 `docs/review/RESPONSE.md`에 적는다.

## 1. 공유용 이미지 템플릿 (사망 화면) — 우선
- 기획서 '화면 구성 6. 사망 화면: 공유용 이미지'
- 묘비(이름, 출생–사망 연도, 묘비명), 연표 5줄, 업적 칩, 시드, 모드를 담는 1080×1350 카드
- 형식: 순수 SVG 템플릿 1장(`assets/share/template.svg`) + 자리표시자 목록. 외부 폰트·이미지 없이 브라우저에서 캔버스로 그릴 수 있어야 한다
- 화면 디자인 토큰은 `src/ui/styles.css` 맨 위 `:root` (원고지 녹색 괘선, 먹색 글씨, 인주 빨강)

## 2. 생활 사건 풀 아이콘 5개
- 병원·몸·밥상·연애·육아 (`src/engine/pools.ts`의 POOL_LABEL)
- 24×24, 선 두께 1.7, `currentColor` 단색 SVG (`src/ui/icons.tsx`와 같은 규격) → `assets/icons/pool-*.svg`

## 3. 통계 보정 자료 (출처 포함 JSON)
지금 시뮬레이터는 일부 목표만 맞춘다. 아래 표가 있으면 연령별로 맞출 수 있다. `data/reference/*.json`, 각 값에 출처 URL과 기준 연도.
- 2024 사망원인통계: 연령대(10세 단위)×성별 사망 원인 비중 상위 10
- 2024 혼인·이혼 통계: 연령별 초혼율(남/여), 연령별 이혼율
- 2024 출생 통계: 모(母) 연령별 출산율
- 국민건강보험 진료비 통계: 흔한 질환 30개의 연간 유병률·평균 본인부담금 (의료 사건 수치 검증용)
- 국민건강영양조사: 연령대별 나트륨·당·단백질 섭취량, 비타민D 결핍률, 빈혈 유병률 (영양 사건 수치 검증용)

## 4. 사건 문장 교정 표본
- `npm run validate` 뒤 아래 스크립트로 풀마다 50개씩 뽑아 읽고, 어색한 한국어·사실 오류·조사 오류를 `docs/review/text-notes.md`에 사건 id와 함께 적어 주면 고친다.
- `npx tsx -e "import {EVENTS} from './src/engine/data'; for (const e of EVENTS.filter(x=>x.pool==='physiology').slice(0,50)) console.log(e.id, e.title, e.text)"`
