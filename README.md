# 대한민국에서 태어났다

성인용 텍스트 인생 시뮬레이션. 2026년 대한민국 어딘가에서 태어나 1년씩 살다가 죽는다.
기획 문서는 [`대한민국_인생_시뮬레이터_기획서.md`](./대한민국_인생_시뮬레이터_기획서.md), 이 저장소는 그 로드맵 1단계(MVP)다.

> 청소년이용불가 등급을 전제로 한다. 범죄·폭력·중독·자살 위기 같은 소재를 다루지만
> 수법은 요약만 하고(대본·도구·구하는 법 없음), 실존 인물 이름은 쓰지 않는다.
> 미성년자에게는 연애·성적 시스템이 열리지 않는다. 위기 사건에는 실제 신고·상담 번호(자살예방 109, 학교폭력 117, 청소년 1388, 국방헬프콜 1303, 보이스피싱 112·1332)를 함께 보여 준다.

## 실행

```bash
npm ci
npm run dev          # 개발 서버
npm run validate     # 사건 데이터 검사 (스키마·조건식·확률 상한·생애 단계별 사건 수)
npm run sim -- --n 10000 --mode drama   # 1만 명 자동 플레이, 보정표와 비교
npm test             # vitest
npm run build        # 타입 검사 + 정적 빌드 (dist/)
npm run build:artifact   # JS·CSS를 넣은 HTML 한 장 (dist-artifact/lifesim.html)
```

Node 22 기준. `.npmrc`의 `legacy-peer-deps=true`는 npm의 피어 의존성 해석 버그를 피하려는 것이다.

  world.json           모드 곡선, 정당·대학 이름(가상), 뉴스 문구, 사망 원인표

사건을 추가하려면 `data/events/`나 `data/arcs/`에 JSON을 넣고 `src/engine/data.ts`의 목록에 한 줄을 더한 뒤
`node tools/event-editor/format.mjs && npm run validate`를 돌린다.

## 엔진 요약

**1년 루프** (`src/engine/game.ts`): ① 연초(나이 +1, 마일스톤) → ② 세계 갱신(경제·정치·안보·재난 뉴스) → ③ 자유 행동(시간 포인트) → ④ 사건 0~3개 → ⑤ 연말 결산(성장·노화·돈·관계·건강) → ⑥ 사망 판정.

**시드**: `cyrb128 + sfc32`. 난수는 용도마다 다른 스트림에서 뽑는다(`rngFor(seed, 'events', age)` 등).
활동이 난수를 몇 번 쓰든 사건 추첨용 주사위 순서는 밀리지 않고, 같은 시드·같은 선택이면 같은 인생이 나온다.

**사건 확률** (`eventEngine.ts`): `P = p0 × A(나이) × Π보정 × D(디렉터) × M(모드)`, 하한 1e-6, 상한 0.95.
조건식은 `eval` 없이 작은 파서로 해석한다(`conditions.ts`).

**디렉터** (`director.ts`): 긴장도·평온한 해 수를 보고 그해 사건 수를 정한다. 사건이 모자라면 `filler: true`인 일상 사건만으로 채운다.

**사망** (`health.ts`): 2024 생명표에 맞춘 곰페르츠-메이크햄 곡선 × 건강 상대위험 + 사건이 만든 위험(암, 전쟁, 사고).
사건 사망이 생명표 위에 더해지므로 기본 위험에 `BASE_HAZARD_SCALE`을 곱해 시뮬레이터로 맞춘다.

**돈** (`game.ts` 연말 결산): 필수 생활비(물가·지역·가구원 수) + 그 이상 번 돈의 55%를 쓴다. 생계급여, 실질 연금, 개인회생이 있다.

**전쟁** (`world.ts`): 긴장도가 평균 45로 돌아가는 무작위 보행. 도발(연 8%)이 긴장을 올리고, 75 이상이면 국지전, 85 이상이면 드물게 전면전.
전면전은 1~2년 뒤 휴전 70% / 통일 20% / 계속 10%. 전쟁 중에는 경제 위기, 주가·집값 하락, 전쟁 사망 위험이 붙는다.

## 기획서와 다르게 한 것

1. **모드 배수를 '평생 확률' 기준으로 매긴다.** 기획서 예시처럼 드라마 모드에서 연간 확률에 ×3을 곱하면
   학교폭력처럼 해마다 기회가 오는 사건은 평생 경험률이 62%까지 올라간다. 그래서 사건의 평생 확률(1−(1−p0)^해당 연수)을 구해
   흔한 사건은 ×1, 드문 사건일수록 큰 배수를 받게 했다(`world.json`의 `modes.*.curve`).
   기획서의 계산 예시(현실 6.3%, M=3이면 18.9%)는 M을 직접 넣으면 그대로 재현된다 — 테스트로 확인할 예정.
2. **인구통계 사건은 모드 배수를 받지 않는다** (`noMode: true`). 결혼·출산·이혼·부모 사망 같은 사건까지 부풀리면 인생 전체가 비현실적이 된다.
3. **조건 없는 선택지는 4개까지.** 조건부 선택지(상황에 따라 하나만 보이는 것)는 더 둘 수 있다.
